
# Go IM System (简易即时通讯系统)

基于纯 Go 语言（Golang）编写的轻量级、终端模式的即时通讯（IM）系统。本项目通过原生 TCP Socket 通信，结合 Goroutine 和 Channel 构建了高并发的服务端与客户端。

## 🌟 功能特性

- **用户上线/下线广播**：用户连接或断开时，自动向所有在线用户广播状态。
- **公聊模式（群聊）**：用户发送的消息会广播给当前所有在线用户。
- **私聊模式**：支持向指定的其他在线用户发送私人消息（格式：`to|用户名|消息内容`）。
- **查询在线用户**：用户可以随时查询当前有多少用户正在线（输入 `who`）。
- **更新用户名**：默认使用 IP:Port 作为用户名，支持自定义修改（格式：`rename|新名字`）。
- **超时强踢机制**：如果用户超过 5 分钟没有任何活跃动作（发消息），服务端将自动释放连接并将其踢下线。

## 🛠️ 技术栈

- **语言**：Go 语言
- **网络通信**：原生 `net` 包 (TCP Socket)
- **并发控制**：Goroutine, Channel, `sync.RWMutex`, `select` 阻塞机制

## 🚀 快速启动

你需要分别启动服务端和客户端。建议打开多个独立终端进行测试。

### 1. 启动服务端
打开终端进入项目根目录，运行以下命令启动服务端：
```bash
go run main.go server.go user.go
```
*服务端默认监听本地的 `127.0.0.1:8888` 端口。*

### 2. 启动客户端
打开全新的终端，运行以下命令启动客户端：
```bash
go run client.go
```
*客户端启动后，根据控制台的菜单提示，输入数字即可体验不同的聊天��式：*
- 输入 `1` 进入公聊模式
- 输入 `2` 进入私聊模式
- 输入 `3` 修改自身用户名
- 输入 `0` 退出

**提示：** 你可以同时打开多个终端运行客户端命令，以模拟多人在线聊天的场景！

## 📄 项目结构

```text
.
├── server.go    # 服务端核心逻辑，负责监听、连接分发与广播消息
├── user.go      # 用户实体抽象，负责单个管道监听、业务逻辑分发(私聊/公聊)
├── main.go      # 服务端启动入口
└── client.go    # 客户端核心逻辑，带终端菜单的交互式聊天客户端
```
